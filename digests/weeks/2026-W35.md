## 关闭周期中的方向

### Verification & Recovery

- **`new_signal` · verifiable-answer-provenance** — 支撑：[BLIP](../../papers/2608.25210.md)；置信度：**中**。把 provenance 从相关性提示提升为同模型可执行的答案复现 witness，但复现错误答案仍不是 correctness 或 business truth。
- **`new_signal` · evidence-gated-catalog-enrichment** — 支撑：[TRACE](../../papers/2608.20844.md)；置信度：**中**。把多源证据发现、候选归一、独立审查和写入授权拆开；当前证据仍不能隔离 Judge、多 Agent 或搜索的独立贡献。
- **`new_signal` · ontology-traceable-enterprise-evidence** — 支撑：[KDAF](../../papers/2608.20661.md)；置信度：**中**。实体边界和来源链可以改善 citation traceability、阻断跨公司泄漏，却没有提高答案正确率；简单 metadata filter 仍是缺失对照。
- **`new_signal` · verified-inference-pipeline-admission** — 支撑：[Bolo](../../papers/2608.20525.md)；置信度：**中**。fresh-environment runnability 与静态 model-input-output dataflow 可以成为交付前 admission gate，但仍没有验证 task-specific output behavior。
- **`new_signal` · governed-scientific-claim-workflow** — 支撑：[Brain Researcher](../../papers/2608.19902.md)；置信度：**中**。不可变 execution bundle 之后仍需统计、测量和主张范围审查；package-level 对照与已观察到的 reviewer miss 限制了自动治理的因果与可靠性结论。

### Planning & Semantic Interaction

- **`new_signal` · adaptive-probing-typed-relational-control** — 支撑：[ReAct-SQL](../../papers/2608.22651.md)；置信度：**中**。matched ablation 把主动数据库探查和 typed composition 拆成两个控制层，且两者的边际收益会随 workload 的主要瓶颈反转。
- **`new_signal` · dependency-layer-decomposition-control** — 支撑：[VAT decomposition](../../papers/2608.23395.md)；置信度：**中**。固定 orchestrator 后扫描 worker partition 是更干净的分工实验，但四项 headline tests 均未通过 Holm correction，不能宣称中间粒度或更多 Agent 更优。
- **`new_signal` · artifact-driven-workflow-compilation** — 支撑：[Artic](../../papers/2608.21341.md)；置信度：**中**。显式 artifact I/O、确定性 control transfer、local gates 与 versioned retry 组成可靠 workflow package，但缺少隔离 artifact materialization 的匹配对照。

### Execution / Grounding interfaces

- **`new_signal` · auditable-computational-campaign** — 支撑：[MAESTRO](../../papers/2608.20434.md)；置信度：**中**。typed state 把大规模科学数据整理和多保真 deterministic tools 连成可回放 campaign；多 Agent / reflection 的独立增益与完整 compute 成本仍未隔离。
- **`new_signal` · dataset-snapshot-skill-interface** — 支撑：[Scientific Data Skills](../../papers/2608.19625.md)；置信度：**低**。带快照与出处的 dataset skill 可以作为持久 grounding interface，但发现收益与两阶段路由、注册和人工信息整理混杂，实际 invocation、drift 与维护成本未测试。

## 跨方向合成（不是趋势声明）

本周最重要的共同问题不是某一种 Agent 架构，而是 **correctness contract 应放在哪一层**。BLIP、KDAF、TRACE、Bolo 与 Brain Researcher 分别检查答案复现、证据归属、生产写入授权、可运行/dataflow admission 与科学主张可接受性；这些 measurement object 互不等价。把它们压成一个“grounded / verified”分数，会同时掩盖 false success 与过度拒绝。

规划侧也出现了一个更严格的 baseline 要求：ReAct-SQL 说明 `adaptive probing + typed deterministic substrate` 本身就能解释大量收益；VAT sweep 没有为“更多 worker 更好”提供经过多重校正的证据；Artic 又把流程收益打包在显式 artifact、routing、gates 和 retry 中。因此复杂 orchestration / multi-agent claim 下一步应固定模型、接口、预算和验证面，只改变一个 control boundary。

SciDSK 与 MAESTRO 进一步提醒成本不能只看在线 token：人工语义整理、快照维护、deterministic scientific compute、trace storage 和后续验证都是完整 data-work loop 的成本组成。

- **地图决定：** `preserve`。本周 10 项原生接受全部为 canonical `early_signal`，绑定 10 个不同 direction key；没有任何方向获得第二项独立同键支撑，因此没有 durable Field Map edit 通过证据门槛。
- **研究设计含义：** 后续 Data Agent 实验应把 `business semantics → plan/control → execution → provenance/reproduction → artifact/claim correctness → recovery/delivery` 作为分层 correctness matrix，并在固定 tool/model/resource budget 下对每个机制提供最接近的匹配对照。
