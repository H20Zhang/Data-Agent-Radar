## 本周期方向

### Learning & Reuse

- **`new_signal` · workload-adaptive-structured-reuse** — 支撑：[Agentic Data Cracking](../../papers/2608.31082.md)；置信度：**medium**。它把一次查询已经支付过的原文读取变成后续不同查询可复用的 evidence-backed structure：在作者构造的 related-query locality 下，mean prefill 从 **189K 降到 87K tokens**，mean API cost 从 **$0.26 降到 $0.12**，约 **53%**；但没有同预算的 demand-only persistent cache，对真实 workload locality、动态 corpus 的 stale-state / invalidation / permission / maintenance cost 也没有闭合。

## 跨方向判断（不是趋势声明）

W36 只有一个 native acceptance，因此最重要的不是把“结构化复用”升级成趋势，而是明确 **reuse 的 break-even contract**。Agentic Data Cracking 证明了一件较窄但重要的事：当多个查询会重复触达同一批长文档时，已经发生的 document prefill 可以被转成持久的部分结构，并用当前一次额外 decode 换未来更少的 raw-document read；同时，90th percentile 的 paired cost ratio 达到 **1.24× baseline**，直接暴露了没有 reuse 时的负收益边界。

对 Data Agent 来说，这把 Learning & Reuse 与 Data Discovery & Grounding 连在了同一个生命周期问题上：**该不该保留 state，不由“能不能抽出来”决定，而由后续命中概率、重新获取成本、失效风险和维护成本共同决定。** 现有证据只在静态 corpus 与人工构造 locality 下验证前三者的一部分；对企业数据，下一步必须把 staleness、版本/权限变化、reverification 与 store growth 计入完整账本。

- **地图决策：** `preserve`。本周唯一 native acceptance 的 canonical `map_delta=early_signal`，且 `workload-adaptive-structured-reuse` 没有第二个独立 same-key support，因此不修改 durable Field Map。
- **研究设计含义：** 下一轮 persistent data-state 实验应至少加入同预算 **demand-only cache**、无持久化 reacquisition、以及带 drift/invalidation 的 workload 三类控制；固定 answer model、tool surface、raw evidence 与总资源后，再比较 speculative materialization 是否真的超过简单缓存。
