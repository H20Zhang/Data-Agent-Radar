## 关闭周期中的方向

### Verification & Recovery

- **`new_signal` · verifiable-answer-provenance** — 支撑：[BLIP](../../papers/2608.25210.md)；置信度：**中**。把 provenance 从“相关来源”推进为可重新执行的答案复现 witness；它证明的是当前模型答案可复现，不是答案正确、业务真实或完整多工具 workflow 的 provenance。
- **`new_signal` · evidence-gated-catalog-enrichment** — 支撑：[TRACE](../../papers/2608.20844.md)；置信度：**中**。把多源证据发现、候选归一、审查和生产写入授权拆开；当前四类 verdict 允许 UNVERIFIED 写入，且没有匹配的 Scout-only / no-Judge 对照。
- **`new_signal` · ontology-traceable-enterprise-evidence** — 支撑：[KDAF](../../papers/2608.20661.md)；置信度：**中**。企业来源链和公司实体边界改善 citation traceability、消除测试池中的跨公司泄漏，却没有提高答案正确率；简单 metadata filter 仍是关键缺失对照。
- **`new_signal` · verified-inference-pipeline-admission** — 支撑：[Bolo](../../papers/2608.20525.md)；置信度：**中**。fresh-environment runnability 与静态 model-input-output dataflow 可以形成交付前准入层，但 task-specific output behavior 仍未验证，且部分提升伴随显著更高成本。
- **`new_signal` · governed-scientific-claim-workflow** — 支撑：[Brain Researcher](../../papers/2608.19902.md)；置信度：**中**。执行成功以后继续审查方法、统计和 claim scope，并保留 blocked / rejected / deferred 状态；package-level 对照和一次已观察到的方向性审查漏检限制了自动治理的因果与可靠性结论。

### Planning & Semantic Interaction

- **`new_signal` · adaptive-probing-typed-relational-control** — 支撑：[ReAct-SQL](../../papers/2608.22651.md)；置信度：**中**。同一模型、hints 和 judge 下的三阶段对照显示，主动数据库探查与 typed relational control 是两个可分离控制层，而且主要瓶颈会随 workload 在 grounding 与 composition 之间切换。
- **`new_signal` · dependency-layer-decomposition-control** — 支撑：[VAT decomposition](../../papers/2608.23395.md)；置信度：**中**。固定 orchestrator 后扫描 worker partition 提供了更干净的多 Agent 分工实验，但四项 headline tests 均未通过 Holm correction；点估计更高不足以证明“更多 Agent”或中间粒度最优。
- **`new_signal` · artifact-driven-workflow-compilation** — 支撑：[Artic](../../papers/2608.21341.md)；置信度：**中**。显式 artifact I/O、确定性 control transfer、local gates 与 versioned retry 组成可靠 workflow package；缺少保持 calls、prompts、gates 与预算一致而只移除 artifact materialization 的匹配对照。

### Execution & Transformation

- **`new_signal` · checked-bounded-tool-lowering** — 支撑：[SkillEffect](../../papers/2608.17007.md)；置信度：**中**。把模型程序在 tool dispatch 前降为受检的有界 IR，可以显著降低峰值内存并提高 hard-cap completion；覆盖仍依赖人工 relation plugin，认证还可能重复扫描输入，resource-safe execution 也不等于最终 artifact correctness。
- **`new_signal` · dual-view-versioned-workspace** — 支撑：[StagedWorkspace](../../papers/2608.18050.md)；置信度：**中**。固定 harness 的 read ablation 支持 parsed retrieval view + native artifact 双视图，但没有隔离 content-hash synchronization 本身；ingestion、后台 parsing 与 sandbox 成本也未进入主成本。
- **`new_signal` · auditable-computational-campaign** — 支撑：[MAESTRO](../../papers/2608.20434.md)；置信度：**中**。typed shared state 把文献、结构清洗、多保真 deterministic tools 和候选交付连接成可回放 campaign；多 Agent / reflection 的独立贡献与完整 compute 成本没有匹配隔离，最终结果仍是模拟候选而非实验真值。

### Data Discovery & Grounding

- **`new_signal` · dataset-snapshot-skill-interface** — 支撑：[Scientific Data Skills](../../papers/2608.19625.md)；置信度：**低**。带快照、出处、文件语义和使用指导的 dataset skill 可以成为持久 grounding interface；发现收益与两阶段路由、注册和人工信息整理混杂，实际数据调用、检查执行、漂移与维护成本未测试。

## 跨方向合成（不是趋势声明）

八月最重要的证据不是某一种 Agent 架构，而是 **Data Agent 的 correctness object 必须分层**。SkillEffect 检查资源义务，Bolo 检查 runnable/dataflow admission，StagedWorkspace 检查工作区访问面，KDAF 检查来源归属，BLIP 检查答案可复现性，TRACE 检查写入授权，Brain Researcher 检查科学主张可接受性。它们分别回答不同问题；把这些对象压成一个“grounded / verified / executable”总分，会同时掩盖 false success、错误业务含义和过度拒绝。

第二个更有判别力的结果来自 **control placement，而不是 orchestration 复杂度**。ReAct-SQL 的匹配对照说明 probe policy 与 typed representation 的价值取决于 workload 瓶颈；VAT sweep 没有得到经过 multiplicity correction 的“更多 worker”证据；Artic、TRACE、MAESTRO 和 Brain Researcher 的 headline 又同时改变多个控制面。因此组件级 claim 下一步应固定 actor/model、tool surface、verification surface 和总预算，只干预一个 planning / execution / verification boundary。

第三个边界是 **完整成本会从在线 token 转移到离线 substrate 与维护**。SkillEffect 需要 relation-specific plugin 与认证扫描；SciDSK 需要人工语义整理和快照维护；Bolo 的部分覆盖提升伴随更高 API 成本；Brain Researcher 的长 episode 包含大量 turns、tool calls 和 cache-read tokens；MAESTRO、Artic 等又没有给出完整 end-to-end compute / retry 预算。没有把 construction、curation、verification、recovery 与 refresh 纳入核算，就不能把“更可靠”直接解释成“更高效”。

- **地图决定：** `preserve`。本月 12 项原生接受全部为 canonical `early_signal`，并绑定 12 个不同 direction key；没有方向获得第二项独立同键支撑，因此没有 durable Field Map edit 通过 `map_delta` 证据门槛。
- **研究设计含义：** 后续 Data Agent 实验应把 `business semantics → plan/control → execution/state → provenance/reproduction → artifact/business/claim correctness → recovery/delivery` 作为分层 correctness matrix；对 orchestration、multi-agent、search、memory 或 verification 的机制归因，都应在匹配接口与完整资源预算下单独干预。
