## Directions in the closed period

### Verification & Recovery

- **`new_signal` · verifiable-answer-provenance** — Support: [BLIP](../../papers/2608.25210.en.md); confidence: **medium**. Provenance moves from a relevant-source hint to an executable answer-reproduction witness. It establishes reproducibility of the current model answer, not answer correctness, business truth, or provenance for a complete multi-tool workflow.
- **`new_signal` · evidence-gated-catalog-enrichment** — Support: [TRACE](../../papers/2608.20844.en.md); confidence: **medium**. Multi-source evidence discovery, candidate normalization, review, and production-write authority are separated. The current four-verdict policy still permits UNVERIFIED writes, and no matched Scout-only / no-Judge control isolates the mechanism.
- **`new_signal` · ontology-traceable-enterprise-evidence** — Support: [KDAF](../../papers/2608.20661.en.md); confidence: **medium**. Enterprise provenance chains and company-identity boundaries improve citation traceability and remove cross-company leakage in the test pool without improving answer correctness; a simple metadata-filter control remains missing.
- **`new_signal` · verified-inference-pipeline-admission** — Support: [Bolo](../../papers/2608.20525.en.md); confidence: **medium**. Fresh-environment runnability plus static model-input-output dataflow can form a pre-delivery admission layer, while task-specific output behavior remains unverified and some coverage gains carry substantially higher cost.
- **`new_signal` · governed-scientific-claim-workflow** — Support: [Brain Researcher](../../papers/2608.19902.en.md); confidence: **medium**. Successful execution remains subject to method, statistics, and claim-scope review with blocked / rejected / deferred outcomes retained. Package-level controls and one observed directionality-review miss bound causal and reliability claims about automated governance.

### Planning & Semantic Interaction

- **`new_signal` · adaptive-probing-typed-relational-control** — Support: [ReAct-SQL](../../papers/2608.22651.en.md); confidence: **medium**. A three-stage comparison under the same model, hints, and judge separates active database probing from typed relational control, with the dominant bottleneck shifting between grounding and composition across workloads.
- **`new_signal` · dependency-layer-decomposition-control** — Support: [VAT decomposition](../../papers/2608.23395.en.md); confidence: **medium**. Sweeping worker partitions under a fixed orchestrator gives a cleaner multi-agent decomposition experiment, but none of the four headline tests survives Holm correction; a higher point estimate does not establish “more agents” or an optimal intermediate granularity.
- **`new_signal` · artifact-driven-workflow-compilation** — Support: [Artic](../../papers/2608.21341.en.md); confidence: **medium**. Explicit artifact I/O, deterministic control transfer, local gates, and versioned retry form a reliable workflow package, but there is no matched control that preserves calls, prompts, gates, and budget while removing artifact materialization alone.

### Execution & Transformation

- **`new_signal` · checked-bounded-tool-lowering** — Support: [SkillEffect](../../papers/2608.17007.en.md); confidence: **medium**. Lowering agent programs into checked bounded IR before tool dispatch can sharply reduce peak memory and improve hard-cap completion. Coverage still depends on manually authored relation plugins, certification can rescan the input, and resource-safe execution is not final-artifact correctness.
- **`new_signal` · dual-view-versioned-workspace** — Support: [StagedWorkspace](../../papers/2608.18050.en.md); confidence: **medium**. A fixed-harness read ablation supports exposing both parsed retrieval views and native artifacts, but it does not isolate content-hash synchronization itself; ingestion, background parsing, and sandbox costs also sit outside the main accounting.
- **`new_signal` · auditable-computational-campaign** — Support: [MAESTRO](../../papers/2608.20434.en.md); confidence: **medium**. Typed shared state connects literature, structure cleaning, multi-fidelity deterministic tools, and candidate delivery into a replayable campaign. The independent contribution of multi-agent/reflection and full compute cost remain unisolated, and the final candidates are simulation results rather than experimental truth.

### Data Discovery & Grounding

- **`new_signal` · dataset-snapshot-skill-interface** — Support: [Scientific Data Skills](../../papers/2608.19625.en.md); confidence: **low**. A sourced, versioned dataset skill can become a persistent grounding interface carrying file semantics and operating guidance. Discovery gains remain confounded with two-stage routing, registration, and manual curation; actual invocation, executed checks, drift, and maintenance cost are untested.

## Cross-direction synthesis (not a trend claim)

The strongest August evidence is not for one agent architecture but for **layering the Data Agent correctness object**. SkillEffect checks resource obligations; Bolo checks runnable/dataflow admission; StagedWorkspace checks workspace access surfaces; KDAF checks provenance attribution; BLIP checks answer reproducibility; TRACE checks write authorization; Brain Researcher checks scientific-claim admissibility. These answer different questions. Collapsing them into one “grounded / verified / executable” score hides false success, wrong business meaning, and over-rejection at the same time.

A second discriminating result concerns **control placement rather than orchestration complexity**. ReAct-SQL's matched comparison shows that the value of probe policy versus typed representation depends on the workload bottleneck; the VAT sweep provides no multiplicity-corrected evidence that more workers are better; and the headline packages in Artic, TRACE, MAESTRO, and Brain Researcher change several control surfaces at once. A component-level claim should therefore hold actor/model, tool surface, verification surface, and total budget fixed while intervening on one planning / execution / verification boundary.

The third boundary is **full cost moving from online tokens into offline substrate and maintenance**. SkillEffect requires relation-specific plugins and certification scans; SciDSK requires manual semantic curation and snapshot maintenance; some Bolo coverage gains carry higher API cost; long Brain Researcher episodes use large numbers of turns, tool calls, and cache-read tokens; and systems such as MAESTRO and Artic still omit complete end-to-end compute / retry budgets. Reliability cannot be equated with efficiency unless construction, curation, verification, recovery, and refresh are included.
