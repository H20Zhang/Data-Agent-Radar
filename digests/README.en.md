# Closed-Period Digests

[中文](README.md) | **English**

This directory contains immutable summaries created after a period has fully closed. Rolling 7/30-day views remain on the home page and are not evidence for later research judgments.

## Stable identities

- ISO week: `digests/weeks/YYYY-Www.md`
- Calendar month: `digests/months/YYYY-MM.md`
- English mirror: append `.en.md` to the stable identity

The first successful update after a boundary creates the prior complete period once. A correction must be appended with an explicit date; a closed digest is never silently rewritten.
