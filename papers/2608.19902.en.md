# Brain Researcher: Constrain Executable Analyses to Defensible Scientific Claims

[中文](2608.19902.md) | **English** · [Home](../README.en.md) · [Research Library](../library/README.en.md)

[Paper](https://arxiv.org/abs/2608.19902) · **Importance: 4/5**

> **Research delta.** Brain Researcher puts data/tool resolution, method constraints, execution evidence, statistical review, claim scope, and memory writeback in one governed loop. A claim may still be qualified, blocked, rejected, or deferred after its analysis code runs successfully.

## Problem

A scientific agent can run valid code while choosing the wrong method, leaking information, optimizing an incomplete criterion, or treating stability on one dataset as independent replication. Executable output is therefore not a scientific conclusion.

## Mechanism

A workspace-local coding harness uses BR-MCP to access a knowledge graph, data/resource resolvers, a typed tool registry, a constraint compiler, versioned execution backends, and a commitment gate. Execution is stored in an immutable run bundle. Scientific review checks statistics, measurement, constructs, generalization, and claim scope. Claims end as `accepted / qualified / revised / blocked / rejected / deferred`; only accepted or qualified claims may enter append-only memory.

The loop is:

`ground → compile conditions → commit plan → execute → inspect immutable bundle → scope claim → recover or deliver → gated memory`

## Closest comparison

The quantitative benchmark compares the same seven coding-agent surfaces with and without Brain Researcher. The off condition removes the registry, knowledge graph, and constraint layer together, so it supports the package but does not attribute gains to one component.

The HCP and TRIBE non-BR sessions do not match prompts, budgets, history, human intervention, or stopping rules. They cannot show that the system caused better research progression.

## Decisive evidence

- Across 60 routing tasks and seven models, Correct route/tool@1 rises from **23.3% to 93.6%**; Capability@1 goes from 49.8% to 94.5%, and Handoff@1 from 47.4% to 76.1%. Every model improves, but registry, KG, and constraints switch as a bundle.
- On 50 question sets, verified groundedness rises from **4.6% to 22.0%**. Most outputs still fail the verification threshold; among non-verified rows, 65% use real but off-topic sources and 28% are only partially supporting.
- A 480-specification NeuroMark multiverse exposes estimator dependence: NM-H2 is favorable in 100% of Pearson/Spearman contrasts and 0% of partial-correlation/mutual-information contrasts. The system preserves the split rather than selecting one result.
- All five prespecified SUDMEX associations are rejected, and 0/70 exploratory results survive FDR. A cross-cultural ALE interpretation is blocked because cells contain only 6–8 experiments, below the recommended 17.
- The frozen HCP workflow beats a matched reconstruction, but same-cohort search, residualization outside folds, and failed calibration repair leave `scientific acceptance=false`. TRIBE's first new-source endpoint fails Holm correction and closes as conflicting/inconclusive.

## Cost and failure boundary

BR-KG contains 745,949 nodes and 2,461,469 relationships. Of 400 manually audited records, only 280 are fully correct; others are incomplete, inherited integration errors, or BR-side errors. One SUDMEX episode runs for about six days with 2,350 assistant turns, 1,347 tool calls, roughly 180.2M cache-read tokens, and an approximate $140 list-price-equivalent cost.

Automated review missed a sign-blind NM-H2 rule that treated significant effects in the wrong direction as favorable; a human found the error. Later calibration shares provenance with the corrected policy and is an internal-consistency check, not a deployed error rate.

Immutable bundles and checksums establish execution and artifact lineage, not biological truth. Scientific claims still require expert inspection, external data, and independent replication.

## Claim ceiling

The evidence strongly supports a complete, auditable scientific data-work loop that preserves negative results. It does not causally isolate the KG, multi-agent, automated-review, or memory components, and automated review does not replace scientific judgment.

## Field-map consequence

This is an `early_signal` in **Verification & Recovery**, connected to planning, execution, and delivery. It clearly separates successful execution from a defensible claim; one package-level paper does not change the stable map.
