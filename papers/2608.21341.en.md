# Artic: Compile Natural-Language Workflows into Explicit Artifacts and Control Flow

[中文](2608.21341.md) | **English** · [Home](../README.en.md) · [Research Library](../library/README.en.md)

[Paper](https://arxiv.org/abs/2608.21341) · **Importance: 3/5**

> **Research delta.** Artic compiles a natural-language workflow into a semi-structured process with declared reads/writes, explicit branches, artifact constraints, and deterministic control transfer. Failed artifacts are not committed, and retries resume from the last valid version.

## Problem

Long or branching textual workflows leave data dependencies for the executor to infer and require it to remember the entire control flow under context pressure. A final answer may look correct while using the wrong intermediate artifact or skipping a required step.

## Mechanism

The compiler extracts artifact I/O, branches/loops, schemas, and constraints and optimizes local context and control burden. Static checks verify availability, types, and routes. An LLM decomposes source behavior into local obligations and uses scenario dry runs to compare source and compiled regions. The runtime versions artifacts, withholds failed outputs, feeds diagnostics into retries, and resumes from the latest valid state.

## Closest comparison

The strongest control is Code: in the same harness, a coding agent implements the workflow in Python plus LLM calls. It is stronger than Text, which puts the whole procedure in one executor context. Artic jointly adds offline compilation, focused subagents, deterministic branching, schemas, quality gates, and automatic retries. There is no matched control with equal calls, prompts, control flow, and budget but no materialized artifacts.

## Decisive evidence

- Across 11 workflows, 488 cases, and three executors, Artic resolve rates are **85% / 82% / 85%**. Text reaches 62% / 46% / 60%, producing the 28-point headline. The closest Code control reaches 73% / 73% / 72%, so the more defensible gap is **+9 to +13 points**.
- On Medical, six-model cross-model consistency rises from 48% to 80%, and ten-repeat pass^10 from roughly 16% to 72%. These reliability results cover only 25 Medical cases.
- A cumulative Medical ablation reports full 88%, no dry run 80%, then no validation 72%, validation without optimization/dry run 48%, and all three removed 0%. This is not an orthogonal factorial design and does not assign independent causal effects.
- Artic trails Code on Know Your Business and remains 50% on Warehouse Inspection, sometimes below Text/SkillCreator. The package does not dominate every domain.

## Cost and failure boundary

The prototype has about 5.9K Python LOC. Initial GLM-5 compilation has median time below five minutes and mean cost below $3; GPT-5.4 and Sonnet Medical compilation cost $38.19 and $13.27. Headline costs exclude later targeted repairs, and total execution tokens, calls, retries, and end-to-end latency are absent.

Deterministic checks enforce declared I/O, types, and routes. Semantic equivalence `a ≃ b`, source decomposition, and dry runs remain LLM judgments. There is no human-labeled faithfulness set, mutation test, or false-accept rate. A final oracle checks output, not necessarily process conformance or hidden business definitions.

## Claim ceiling

The Artic package of explicit artifact interfaces, deterministic routing, local gates, and versioned retries improves workflow execution in this harness. The evidence does not show that artifacts alone cause the gain, that compilation preserves complete semantics, that total cost is lower, or that business truth is verified.

## Field-map consequence

This is an `early_signal` in **Planning & Semantic Interaction**, connected to Execution & Transformation and Verification & Recovery. It sharpens the question of intermediate artifacts as control interfaces; one paper does not change the stable map.
