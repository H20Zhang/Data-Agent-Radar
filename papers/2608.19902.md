# Brain Researcher：把可执行分析约束为可辩护的科学主张

**中文** | [English](2608.19902.en.md) · [返回首页](../README.md) · [Research Library](../library/README.md)

[Paper](https://arxiv.org/abs/2608.19902) · **Importance: 4/5**

> **Research delta.** Brain Researcher 把数据与工具解析、方法约束、执行证据、统计审查、主张边界和记忆写回放进同一个治理闭环；分析代码运行成功以后，主张仍可以被限定、阻断、拒绝或延期。

## Problem

科学 Agent 可以运行正确的代码，却仍可能选错方法、发生信息泄漏、只优化一个不完整指标，或把同一数据集上的稳定性误写成独立重复。可执行结果因此不是科学结论。

## Mechanism

workspace-local coding harness 通过 BR-MCP 访问知识图谱、数据与资源解析器、typed tool registry、约束编译器、版本化执行后端和 commitment gate。执行被保存为不可变 run bundle；科学审查覆盖统计、测量、构念、泛化和主张范围。主张只能进入 `accepted / qualified / revised / blocked / rejected / deferred` 六种状态，只有 accepted 或 qualified 才能写入 append-only memory。

闭环是：

`ground → compile conditions → commit plan → execute → inspect immutable bundle → scope claim → recover or deliver → gated memory`

## Closest comparison

定量基准在同样七种 coding-agent surface 上比较启用与关闭 Brain Researcher。关闭条件同时移除 registry、知识图谱和约束层，因此只能证明整个 package 的作用，不能把增益归因给某一个组件。

HCP 与 TRIBE 的无 BR 会话并没有匹配 prompt、预算、历史、人工介入和停止规则，不能用来证明系统导致了更好的研究推进。

## Decisive evidence

- 60 个路由任务 × 7 个模型中，Correct route/tool@1 从 **23.3% 提升到 93.6%**；Capability@1 从 49.8% 到 94.5%，Handoff@1 从 47.4% 到 76.1%。七个模型都改善，但 registry、KG 与 constraints 被整体切换。
- 50 个问题集的 verified groundedness 从 **4.6% 到 22.0%**。这仍意味着大多数输出没有达到核验门槛；未核验行中 65% 使用了真实但离题的来源，28% 只有部分支撑。
- NeuroMark 的 480-specification multiverse 暴露出结论对 estimator 的依赖：NM-H2 在 Pearson / Spearman 下 100% 有利，在 partial correlation / mutual information 下 0% 有利；系统保留了这种分裂，而没有选择性汇报。
- SUDMEX 的五项预注册关联全部被拒绝，70 项探索结果在 FDR 后也为 0；跨文化 ALE 因每格只有 6–8 个实验、低于建议的 17 个而阻断机制性解释。
- HCP 的冻结工作流虽优于 matched reconstruction，但 same-cohort search、fold 外 residualization 与校准修复失败使 `scientific acceptance=false`。TRIBE 的首个新来源 endpoint 在 Holm 校正后不显著并被关闭为冲突/不确定。

## Cost and failure boundary

BR-KG 包含 745,949 个节点与 2,461,469 条关系；400 条人工审计中只有 280 条完整正确，另有不完整、上游集成错误与 BR-side 错误。一个 SUDMEX episode 运行约六天，包含 2,350 个 assistant turns、1,347 个 tool calls、约 180.2M cache-read tokens，按列表价估算约 140 美元。

自动审查曾漏掉一个 sign-blind NM-H2 规则，把方向相反但显著的结果错误视为有利；问题由人工发现。后续校准与规则共享来源，因此只说明内部一致性，不能代表部署错误率。

不可变 bundle 与 checksum 能证明执行与产物谱系，却不能证明生物学真实。科学主张仍需专家检查、外部数据与独立重复。

## Claim ceiling

证据强力支持一个完整、可审计且愿意保留负结果的科学数据工作闭环。它不支持对 KG、多 Agent、自动验证或记忆组件的单独因果归因，也不意味着自动审查可以替代科学判断。

## Field-map consequence

该工作作为 `early_signal` 进入 **Verification & Recovery**，并连接规划、执行与交付。它把“执行成功”与“可辩护主张”明确拆开；单篇 package-level 证据不修改稳定地图。
