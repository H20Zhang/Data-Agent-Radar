# Scientific Data Skills：把数据集知识封装为可追溯的 Agent 接口

**中文** | [English](2608.19625.en.md) · [返回首页](../README.md) · [Research Library](../library/README.md)

[Paper](https://arxiv.org/abs/2608.19625) · **Importance: 3/5**

> **Research delta.** SciDSK 不把数据集本体复制进 Agent，而是把特定快照的科学语境、文件结构、使用步骤、质量检查与来源关系整理为可路由、可复用的 skill；它把“找到数据”推进到“知道这份数据该如何解释和准备”。

## Problem

科学数据分散在不同仓库，文档常按人类阅读习惯组织。即使 Agent 找到了候选数据集，也可能不知道文件各自承担什么角色、字段如何对应科学概念、使用前要做哪些准备，以及哪些约束来自可靠来源。

因此关键边界不是单纯的检索召回率，而是：数据集身份、具体快照、文件级语义和可执行指导能否绑定在一个可追溯接口里。

## Mechanism

一个 SciDSK 对应一个数据集快照，底层数据仍留在原仓库。`SKILL.md` 的 frontmatter 提供路由描述、来源、数据集与 skill 标识、许可和快照；正文组织六类信息：数据集概览、访问方式、字段与结构、使用指导、质量检查、来源与引用。

构建过程是：

`权威来源收集 → 事实归一与出处保留 → 按规范编写 → 来源一致性 / 结构 / 包完整性检查 → 修订发布`

Skill Bank 进一步提供六个学科的检索、下载、持久标识和发布前审查。这是静态、版本化的复用状态，不是从使用轨迹中持续学习的记忆。

## Closest comparison

发现实验比较 BM25-Raw、Agent-Raw、把完整 skill 当普通文本检索的 Agent-SciDSK-Text，以及注册为可路由 skill 的 Agent-SciDSK。Agent 条件共享最多 4 次搜索、10 次候选检查与最终排序协议。

但获胜条件会先选择两个学科，再搜索注册资源，而且搜索索引仍使用常规 metadata。它同时改变了学科路由、注册方式、上下文暴露与工作流。真正缺失的简单对照，是使用同样两阶段路由、相同索引、预算与工具，却只提供常规 metadata 的 Agent。

解释实验也没有提供信息量匹配的对照：SciDSK 汇集多个来源中的文件事实与检查步骤，而公开结果只将它与 ScienceDB 页面比较。把同一批事实放进普通结构化文档，才能隔离 skill 封装本身。

## Decisive evidence

- 发现测试包含 72 个数据集、104 条人工复核后的单目标查询。Agent-SciDSK 的 Hit@1 / Recall@5 / MRR / nDCG@5 为 **80.77 / 94.23 / 86.41 / 88.40**；Agent-SciDSK-Text 为 **70.19 / 90.38 / 79.01 / 81.92**。
- Agent-Raw 与 Agent-SciDSK-Text 基本持平：Hit@1 为 **71.15 vs 70.19**，Recall@5 都是 **90.38**。这项负结果说明，把更丰富的 skill 文本直接当普通检索文档并没有观察到优势。
- 文件解释只覆盖 4 个选定案例、24 个原子标准。SciDSK 满足 **23/24**，ScienceDB 页面满足 **22/24**；净增益只有 1 个标准。
- CT 案例中，skill 区分了可见的 196 张切片与数据集报告的 1,576 个文件，并列出连续性、可读性、参数文件和目录完整性检查。这说明整理后的表示能够暴露更具体的文件级指导，但实验没有执行这些检查。

## Cost and failure boundary

成本主要转移到人工选择数据集、汇集 landing page、文件清单、数据字典、论文、许可与版本信息，随后还要归一化、编写、反复审查、分配标识并维护快照。论文没有量化作者与审阅工时、更新吞吐、过期处理、token、tool call、实际重试或运行成本。

发现收益可能主要来自两阶段路由，而不是 skill 内容。解释标准又直接奖励被人工写入 skill 的文件事实和检查清单；4 个案例由作者选择，只使用一名盲化审阅者，也没有置信区间。

论文反复使用“invoke”，但没有实际下载、预处理、下游分析、质量检查执行、失败恢复或最终科学结论评测。它也没有测试恶意或冲突指令、快照漂移和失效策略。

## Claim ceiling

在 2026 年 7 月的封闭 Skill Bank 快照、单一 Qwen harness 与受限 MCP 工具环境中，注册并按学科路由的 SciDSK 整体工作流提高了目标数据集检索；在 4 个案例里，人工整理的 skill 也提供了略多的文件级解释与检查指导。

证据不能把收益归因给 skill 内容、注册、路由或版本字段中的任何单一组件，也没有证明数据调用、检查执行、科学正确性、恢复、安全或规模化维护。

## Field-map consequence

该工作作为 `early_signal` 进入 **Data Discovery & Grounding**，并与 **Learning & Reuse** 相连：数据集知识可以成为带快照与出处的持久 Agent 接口。单篇、系统级且缺少匹配对照的证据不足以修改稳定地图。
