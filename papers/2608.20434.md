# MAESTRO：把材料发现连接成可追踪的计算闭环

**中文** | [English](2608.20434.en.md) · [返回首页](../README.md) · [Research Library](../library/README.md)

[Paper](https://arxiv.org/abs/2608.20434) · **Importance: 4/5**

> **Research delta.** MAESTRO 用 typed message 和共享状态连接文献检索、晶体结构清洗、性质计算、多保真筛选与候选交付，并把 Agent 决策保存为可回放记录；数值工作仍由确定性科学工具完成。

## Problem

计算材料发现通常被拆成文献、结构、描述符、筛选、过程模拟和物理验证等孤立步骤。跨阶段手工传递会丢失来源、假设与失败信息，也难以在新数据到来时重跑。

## Mechanism

一个 Claude Opus 4.6 orchestrator 协调 Literature、Structure、Property 与 Screening specialists。每个阶段使用 `plan → execute → reflect → gate`，通过 typed messages 和 shared state 交接；核心数值由结构检查器、Widom insertion、GCMC、VSA optimization 与 MLP-MD 等工具执行。上下文、推理与决定保存为 JSON。

## Closest comparison

科学结果以 CALF-20 为外部商业材料基线。Agent 机制没有匹配的单 Agent、确定性 pipeline、人工 workflow 或 reflection/gate ablation。论文只能证明完整 MAESTRO package 完成了 campaign，不能把结果归因给多 Agent 或 LLM orchestration。

## Decisive evidence

- 超过 40 万篇论文与 19 万个结构变体进入管线；五个结构工具的严格交集留下 **64,097** 个 computation-ready entries。
- 筛选漏斗从 64,071 → 19,207 → 1,035 → 280 → 205 → 11。最终 10/11 个候选通过干态纯度、湿态保持与 hydrophobicity 三项计算标准。
- 在 RH=1 时，11 个候选保留 93.7–98.8% 干态 CO₂ capacity，而 CALF-20 只保留 6.5%。这些仍是模拟结果，不是实验吸附或传质验证。
- 完整过程模拟改变了简单 proxy 排名：YIWBEN 从 equilibrium VSA 的第 10 上升到完整过程第 2，BELCUT 从第 1 降到第 6。
- 三个月增量运行约处理 300 个新 CIF，没有人工介入；论文只展示一个 selected self-correction 案例，没有总体重试与恢复率。

## Cost and failure boundary

文献 audit 的 precision 只有 77%，且只抽样 100 个接受与 100 个拒绝结果。五工具交集提高可靠性也会牺牲 recall。整个 campaign 包含 43,200 个过程点和 12,046 个 MLP-MD frames，却没有 token、API、wall-time 或硬件总成本。

所有 LLM 决策来自一个模型；prompts、推理参数和完整 tool versions 不足。确定性工具与 trace 支持执行复现和 artifact lineage，但刚性 framework、classical force fields 与筛选阈值仍限制 scientific truth。候选必须经过合成、表征与 transport experiment。

## Claim ceiling

一个 traced LLM-controlled package 成功连接了大规模文献/结构整理与多保真模拟，并产生收敛的计算候选。证据不隔离多 Agent、reflection/gate 或 LLM 规划的价值，也不证明发现了实验上有效的材料。

## Field-map consequence

该工作作为 `early_signal` 进入 **Execution & Transformation**，并连接 Data Discovery & Grounding 与 Verification & Recovery。它显示复杂数据 campaign 可以共享可追踪状态；单篇 package 结果不修改稳定地图。
