# Artic：把自然语言流程编译为显式产物与控制流

**中文** | [English](2608.21341.en.md) · [返回首页](../README.md) · [Research Library](../library/README.md)

[Paper](https://arxiv.org/abs/2608.21341) · **Importance: 3/5**

> **Research delta.** Artic 把自然语言 workflow 编译为声明 reads/writes、显式分支、artifact constraints 与 deterministic control transfer 的半结构化流程；失败产物不会提交，重试从最后一个有效版本继续。

## Problem

长或分支型自然语言流程常把数据依赖留给执行 Agent 猜测，也要求它在上下文压力下记住整个控制流。结果可能最终看似正确，却使用了错误中间产物或跳过必要步骤。

## Mechanism

compiler 提取 artifact I/O、分支/循环、schema 与约束，并优化局部上下文与控制负担。静态检查验证 availability、type 和 route；LLM 把源流程拆成局部 obligation，并用 scenario dry run 比较源与编译区域。runtime 版本化 artifact，约束失败时不提交输出，将诊断反馈给重试，并从最新有效状态恢复。

## Closest comparison

最强对照是同一 harness 中由 coding agent 把流程实现成 Python + LLM calls 的 Code，不是把全部文字塞进一个 executor 的 Text。Artic 同时增加离线编译、focused subagents、确定性分支、schema、quality gates 与自动重试；没有相同调用、prompt、控制流和预算但去掉 materialized artifacts 的匹配对照。

## Decisive evidence

- 11 个 workflow、488 个 case、三个 executor 上，Artic resolve rate 为 **85% / 82% / 85%**；Text 为 62% / 46% / 60%，形成约 28 点 headline；最接近的 Code 为 73% / 73% / 72%，更可辩护的差距是 **+9 至 +13 点**。
- Medical 的六模型 cross-model consistency 从 48% 提升到 80%；十次重复的 pass^10 约从 16% 到 72%。这些可靠性结果只覆盖 25 个 Medical cases。
- Medical 累积 ablation：完整 88%，去 dry-run 80%，再去 validation 72%，保留 validation 但去 optimization/dry-run 48%，三者全去为 0%。这不是正交 factorial，不能分配独立组件因果效应。
- Artic 在 Know Your Business 上低于 Code，在 Warehouse Inspection 上固定 50% 且可低于 Text/SkillCreator；package 并非所有 domain 都占优。

## Cost and failure boundary

prototype 约 5.9K Python LOC。GLM-5 首次 compilation 中位数低于五分钟、平均低于 3 美元；Medical 的 GPT-5.4 与 Sonnet compilation 分别 38.19 与 13.27 美元。headline 成本排除了后续 targeted repairs，也没有总执行 tokens、calls、retry 分布或 end-to-end latency。

确定性检查可以保证声明的 I/O、types 与 routes。`a ≃ b` 的语义等价、source decomposition 和 dry run 仍由 LLM 判断；没有 human-labeled faithfulness set、mutation test 或 false-accept rate。最终 oracle 验证结果，不一定验证真实 process conformance 或隐藏的业务定义。

## Claim ceiling

显式 artifact interfaces、确定性 routing、局部 gates 和版本化 retry 组成的 Artic package 在这个 harness 中改善了 workflow execution。证据不证明 artifact 单独导致收益、compiler 保留完整语义、总成本更低，或业务真实性得到验证。

## Field-map consequence

该工作作为 `early_signal` 进入 **Planning & Semantic Interaction**，并连接 Execution & Transformation 与 Verification & Recovery。它强化“中间产物是控制接口”的问题意识，但单篇证据不修改稳定地图。
